# 🌿 Serene Skin Ritual
> Personalized skincare experience powered by interactive recommendations.

---

## 🚀 Overview
**Serene Skin Ritual** is a modern web application designed to help users discover skincare products tailored to their needs through an interactive quiz-based system.

It combines intuitive UI with smart recommendation logic to create a more engaging and personalized shopping experience.

---

## 🧠 Features
- 🧴 Personalized skincare recommendations  
- 🧩 Interactive quiz system  
- 🛍️ Modern e-commerce interface  
- ⚡ Fast, responsive design  

---

## 🛠 Tech Stack
- React + Vite  
- TypeScript  
- Tailwind CSS  
- shadcn/ui  

---

## ▶️ Run Locally
```bash
npm install
npm run dev
```

---

## 🎯 Vision
To simplify skincare decisions by combining personalization, usability, and clean design into one seamless experience.
